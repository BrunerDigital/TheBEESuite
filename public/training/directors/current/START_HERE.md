# Director training

Open index.html in Chrome, Edge or Safari. Keep the folder together for offline use.

36 narrated videos and 50 task guides are included. Computer-generated narration uses Microsoft Zira. Each video includes captions and a transcript. Use fullscreen for app controls.

Start with school context, family intake and enrollment, then billing, daily operations, communications, staff and reporting. Search the written guides when a specific task arises.

## Demonstration types

- Screen orientation: explains a synthetic app screen.
- Form walkthrough: prepares fields and stops before saving.
- Local saved workflow: real controls save into a separate local training file and reopen the result. This does not certify production transactions, identity provisioning, kiosk credentials or external delivery.
- Narrated procedure: source-reviewed instructional slides for the task.

## Practice and review

Use TRAINER_CHECKLIST.md for practice and PILOT_REVIEW.md for the human director review. No human signoff has been obtained.

The public library is intended for https://thebeesuite.io/resources/director-training. Publication status is recorded separately. Source and recording scripts are included in the local package, not the public library.
