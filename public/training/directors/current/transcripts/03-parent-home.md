# Explain the parent home screen

Synthetic parent view for staff explaining what linked families see.

Narrated, captioned screen orientation. Synthetic preview; no live action is submitted. Timing follows the narrated steps.

## 1. Verify family visibility

After approved onboarding, the guardian should see only their own linked family and children. Stop if a child is missing or unexpected.

## 2. Explain daily information

Show the family where the child status and daily updates appear. A blank or not-marked status needs staff review, not an assumption.

## 3. Separate access from billing

Being able to sign in does not confirm tuition, saved payment methods, autopay or kiosk readiness. Verify each separately.

## 4. Support the parent safely

Use the parent invitation and onboarding guides. Never request the parent’s password or card details by ordinary message.
