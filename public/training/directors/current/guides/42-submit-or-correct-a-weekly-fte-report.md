# Submit or correct a weekly FTE report

Category: Reporting

Before you start: confirm the correct school and role. Use approved source records; perform live changes only within your assigned authority.

1. Open the school’s FTE reporting screen from the dashboard reporting shortcut and confirm the school.
2. Select the intended **Week start** and **Week end**. Check the year and service period.
3. Review enrolled children, schedule counts, FTE count and the source records used for the calculation.
4. Review the weekly billing fields, external agency amount, past-due current-family AR, licensed capacity, payroll, starts and withdrawals. Explain exceptions in **Notes**.
5. Select **Submit FTE Report** for a new report, or **Save FTE Correction** for an editable existing report.
6. Wait for confirmation, then reopen the school/week row and verify the saved values and status.

## Verify the result

The intended school/week appears once with the correct status and values.

## If something goes wrong

An approved locked report requires the authorized correction process; do not create a duplicate week. Wait for pending actions; reopen the record before retrying an uncertain save or send.
