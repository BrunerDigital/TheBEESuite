# Explain parent communications

Parent-side message navigation; sending and recipient review are documented separately.

Narrated, captioned screen orientation. Synthetic preview; no live action is submitted. Timing follows the narrated steps.

## 1. Show the correct family context

Parent messages belong to the signed-in family. Verify the linked family before troubleshooting a conversation.

## 2. Read before responding

Review the conversation context. Staff should choose the smallest correct audience in their communication workspace.

## 3. Review the final message

Check recipients and wording before any send. Drafted text and AI suggestions still require a staff review.

## 4. Verify the send result

An accepted email request is not proof of delivery. If the result is uncertain, inspect the status before sending again.
